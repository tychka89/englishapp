# 📚 Грамматика английского языка — по учебнику Голицинского

Интерактивное веб-приложение для изучения английской грамматики на основе учебника В.Л. Голицинского "Грамматика. Сборник упражнений".

## ✨ Возможности

- 📖 **22 грамматические темы** с подробной теорией
- 📝 **440 интерактивных упражнений** с проверкой ответов
- 💡 **Подсказки** для каждого упражнения
- 📊 **Отслеживание прогресса** с сохранением в браузере
- 🌙 **Тёмная/светлая тема**
- 📱 **Адаптивный дизайн** для мобильных устройств
- 📲 **PWA поддержка** — можно установить как приложение на телефон

## 📚 Темы

### Времена глагола
- Present Simple
- Present Continuous
- Past Simple
- Past Continuous
- Present Perfect
- Past Perfect
- Future Simple
- Смешанные времена

### Части речи
- Артикли (a/an, the)
- Множественное число существительных
- Личные и притяжательные местоимения
- Предлоги времени и места
- Сравнительная и превосходная степень прилагательных
- Модальные глаголы

### Залог
- Страдательный залог (Passive Voice)

### Неличные формы глагола
- Герундий (Gerund)
- Инфинитив (Infinitive)

### Сложный синтаксис
- Условные предложения (Conditionals)
- Косвенная речь (Reported Speech)
- Сложное дополнение (Complex Object)
- Сложное подлежащее (Complex Subject)
- Сослагательное наклонение (Subjunctive Mood)

## 🚀 Быстрый старт

### 📱 Установка на мобильное устройство

**Подробная инструкция:** [INSTALL_MOBILE.md](./INSTALL_MOBILE.md)

**Кратко:**
1. Скачайте код с GitHub (кнопка Code → Download ZIP)
2. Распакуйте архив на телефоне
3. Запустите локально через Termux (Android) или a-Shell (iOS)
4. Откройте в браузере и установите как PWA

### 💻 Локальный запуск на компьютере

```bash
# Клонируйте репозиторий
git clone https://github.com/YOUR_USERNAME/english-grammar-golitsynsky.git

# Перейдите в директорию проекта
cd english-grammar-golitsynsky

# Установите зависимости
npm install

# Запустите dev-сервер
npm run dev

# Откройте http://localhost:3000 в браузере
```

### Сборка для продакшена

```bash
# Создайте production-сборку
npm run build

# Файлы будут в папке dist/
```

## 📱 Установка на мобильное устройство

### iPhone/iPad (Safari)
1. Откройте приложение в Safari
2. Нажмите кнопку "Поделиться" (⬆️)
3. Выберите "На экран «Домой»"
4. Нажмите "Добавить"

### Android (Chrome)
1. Откройте приложение в Chrome
2. Нажмите ⋮ (три точки) в правом верхнем углу
3. Выберите "Установить приложение" или "Добавить на главный экран"
4. Нажмите "Установить"

## 🌐 Деплой на GitHub Pages

1. Установите gh-pages:
```bash
npm install --save-dev gh-pages
```

2. Добавьте в `package.json`:
```json
{
  "homepage": "https://YOUR_USERNAME.github.io/english-grammar-golitsynsky",
  "scripts": {
    "predeploy": "npm run build",
    "deploy": "gh-pages -d dist"
  }
}
```

3. Задеплойте:
```bash
npm run deploy
```

4. Откройте https://YOUR_USERNAME.github.io/english-grammar-golitsynsky
