# 🤝 Руководство по внесению вклада

Спасибо за интерес к проекту! Мы приветствуем любой вклад в развитие приложения.

## 🐛 Нашли ошибку?

1. Проверьте, что ошибка уже не описана в [Issues](../../issues)
2. Создайте новый Issue с описанием проблемы
3. Приложите скриншоты, если возможно
4. Укажите версию браузера и устройства

## 💡 Есть идея для улучшения?

1. Создайте Issue с меткой `enhancement`
2. Опишите вашу идею подробно
3. Обсудите реализацию с мейнтейнерами

## 🔧 Хотите внести изменения в код?

### Процесс работы

1. **Форкните репозиторий**
   - Нажмите кнопку "Fork" в правом верхнем углу

2. **Клонируйте свой форк**
   ```bash
   git clone https://github.com/YOUR_USERNAME/english-grammar-golitsynsky.git
   cd english-grammar-golitsynsky
   ```

3. **Создайте ветку для ваших изменений**
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Внесите изменения**
   - Следуйте существующему стилю кода
   - Добавьте комментарии, если необходимо
   - Протестируйте изменения локально

5. **Закоммитьте изменения**
   ```bash
   git add .
   git commit -m "Add: описание ваших изменений"
   ```

6. **Отправьте в свой форк**
   ```bash
   git push origin feature/your-feature-name
   ```

7. **Создайте Pull Request**
   - Перейдите в ваш форк на GitHub
   - Нажмите "Compare & pull request"
   - Опишите ваши изменения

### Стиль кода

- Используйте TypeScript для всех новых файлов
- Следуйте существующей структуре проекта
- Добавляйте комментарии на русском языке
- Используйте осмысленные имена переменных и функций

### Тестирование

Перед созданием PR:
- Убедитесь, что проект собирается без ошибок: `npm run build`
- Проверьте работу в разных браузерах
- Протестируйте на мобильном устройстве

## 📚 Добавление новых упражнений

Если хотите добавить новые темы или упражнения:

1. Новые темы добавляются в `src/data/additionalTopics.ts`
2. Следуйте структуре существующих тем
3. Убедитесь, что упражнения имеют однозначные ответы
4. Добавьте подсказки для каждого упражнения
5. Проверьте грамматику и орфографию

### Структура темы

```typescript
{
  id: "unique-topic-id",
  title: "Название темы",
  titleEn: "English Title",
  section: "Раздел",
  theory: "Описание теории",
  rules: [
    "Правило 1",
    "Правило 2"
  ],
  examples: [
    "Пример 1",
    "Пример 2"
  ],
  exercises: [
    {
      id: 1,
      question: "Текст вопроса с ___ для пропуска",
      options: ["вариант1", "вариант2", "вариант3", "вариант4"],
      correctAnswer: "правильный ответ",
      hint: "Подсказка для пользователя"
    }
  ]
}
```
