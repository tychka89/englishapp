# 📱 Инструкция по установке на мобильное устройство

## Шаг 1: Скачайте код с GitHub

### Вариант А: Через GitHub приложение (рекомендуется)

1. Установите приложение **GitHub** из App Store или Google Play
2. Откройте репозиторий: `https://github.com/YOUR_USERNAME/english-grammar-golitsynsky`
3. Нажмите кнопку **"Code"** (зелёная кнопка)
4. Выберите **"Download ZIP"**
5. Распакуйте архив

### Вариант Б: Через браузер

1. Откройте в браузере: `https://github.com/YOUR_USERNAME/english-grammar-golitsynsky`
2. Нажмите кнопку **"Code"** → **"Download ZIP"**
3. Скачайте и распакуйте архив на телефоне

---

## Шаг 2: Запустите приложение локально

### Для Android (с Termux)

1. Установите **Termux** из Google Play или F-Droid
2. Откройте Termux и выполните команды:

```bash
# Обновите пакеты
pkg update && pkg upgrade

# Установите Node.js
pkg install nodejs

# Перейдите в папку с проектом
cd /storage/emulated/0/Download/english-grammar-golitsynsky

# Установите зависимости
npm install

# Запустите dev-сервер
npm run dev
```

3. Откройте в браузере: `http://localhost:3000`

### Для iOS (с a-Shell)

1. Установите **a-Shell** из App Store
2. Откройте a-Shell и выполните:

```bash
# Перейдите в папку с проектом
cd ~/Downloads/english-grammar-golitsynsky

# Установите зависимости
npm install

# Запустите dev-сервер
npm run dev
```

3. Откройте в Safari: `http://localhost:3000`

---

## Шаг 3: Установите как приложение (PWA)

### iPhone/iPad

1. Откройте приложение в **Safari** (только Safari!)
2. Нажмите кнопку **"Поделиться"** (квадрат со стрелкой вверх) внизу экрана
3. Прокрутите вниз и выберите **"На экран «Домой»"**
4. Нажмите **"Добавить"** в правом верхнем углу
5. Иконка приложения появится на главном экране

### Android

1. Откройте приложение в **Chrome**
2. Нажмите **три точки** (⋮) в правом верхнем углу
3. Выберите **"Установить приложение"** или **"Добавить на главный экран"**
4. Нажмите **"Установить"** или **"Добавить"**
5. Приложение появится на главном экране

## 🌐 Альтернатива: Деплой на GitHub Pages

Если вы не хотите запускать локально, можете задеплоить приложение на GitHub Pages:

### Автоматический деплой (GitHub Actions)

1. Загрузите код в репозиторий на GitHub
2. Перейдите в **Settings** → **Pages**
3. В разделе **Source** выберите **GitHub Actions**
4. Workflow автоматически задеплоит приложение при каждом push в main

### Ручной деплой

```bash
# Установите gh-pages
npm install --save-dev gh-pages

# Добавьте в package.json:
# "homepage": "https://YOUR_USERNAME.github.io/english-grammar-golitsynsky"
# "scripts": {
#   "predeploy": "npm run build",
#   "deploy": "gh-pages -d dist"
# }

# Задеплойте
npm run deploy
```

После деплоя откройте: `https://YOUR_USERNAME.github.io/english-grammar-golitsynsky`

Затем установите как PWA (см. Шаг 3).

## ⚠️ Важные замечания

### Оффлайн-режим
- После первой загрузки приложение работает **оффлайн**
- Прогресс сохраняется в браузере
- Не очищайте данные браузера, чтобы не потерять прогресс

### Обновления
- Если вы используете GitHub Pages, обновления происходят автоматически
- Если локально — выполните `git pull` и перезапустите `npm run dev`

### Поддерживаемые браузеры
- **iOS**: только Safari для установки PWA
- **Android**: Chrome, Edge, Samsung Internet
- **Десктоп**: Chrome, Edge, Firefox

## 🆘 Решение проблем

### Приложение не устанавливается на iOS
- Убедитесь, что используете **Safari** (не Chrome)
- Проверьте, что сайт открыт по **HTTPS** или **localhost**
- Очистите кэш Safari и попробуйте снова

### Приложение не работает на Android
- Убедитесь, что используете **Chrome**
- Проверьте, что включён JavaScript
- Попробуйте очистить кэш браузера

### Прогресс не сохраняется
- Проверьте, что не включён режим инкогнито
- Убедитесь, что не очищаете данные браузера
- Прогресс привязан к конкретному браузеру и устройству
